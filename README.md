Aero Mood Board

Aero Mood is a creative mood board and a relaxation tool designed to help users connect with their inner atmosphere through curated emotional experiences. It offers a space for creativity, tranquility, and inspiration, blending design, mood mapping, and storytelling.

Features

Quote Generator: Generate random mood-related quotes with a simple button click.

Image Gallery: Display a collection of handpicked images that evoke different moods.

Subscription: Stay updated with the latest content by subscribing via email.

Responsive Design: The website is fully responsive, ensuring a great experience on both desktop and mobile devices.

Technologies Used

HTML: Structure of the website.

CSS: Styling the website to ensure a clean and modern look.

JavaScript: Random quote generator functionality and interactive features.
